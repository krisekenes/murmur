# Murmur 0.4.0 — folders, constellations, and a new Beta UI

This release updates the Beta library with readable conversation cards, folder previews, and more ways to organize your recordings. It also introduces a dark star-field background, custom folder constellations, and a recording indicator that responds to your voice.

**Turn on Beta in the main window to try the updated library.** You can switch back to the classic feed at any time. Both views use the same saved conversations, folders, and scratchpad pages.

## A closer look

### Conversations and folders at a glance

![Murmur Beta library showing folders with multiple transcript previews and unfiled conversation cards](https://raw.githubusercontent.com/krisekenes/murmur/v0.4.0/docs/releases/images/v0.4.0/library.png)

- **Readable conversation cards:** larger transcript previews, dates, primary tags, and source-app labels make it easier to identify a recording.
- **Multiple previews per folder:** folder cards show up to three recent conversations, plus conversation and scratchpad-page counts.
- **Compact constellations:** each folder has its own star pattern and muted accent color. The pattern stays consistent when you rename the folder.
- **Less header clutter:** the library opens directly into your collections and unfiled conversations, without a decorative headline or tagline.
- **Stable hover states:** borders and glows highlight cards without changing their dimensions.

### A layout that adapts to the window

![The updated Murmur library in a narrower window, with three conversation snippets visible in a folder](https://raw.githubusercontent.com/krisekenes/murmur/v0.4.0/docs/releases/images/v0.4.0/compact.png)

The grid adjusts to the available width. Collections and unfiled conversations have separate headings, while search shows matching conversations across folders. Opening and leaving a folder uses a short fade-and-scale transition.

## Organize by dragging

| Drag this… | Onto this… | Result |
| --- | --- | --- |
| A conversation card | Another conversation | Group the conversations into a folder |
| A conversation card | A folder | File the conversation in that folder |
| A folder card | Another folder | Merge all conversations and scratchpad pages into the destination |

The destination folder keeps its name and constellation when folders merge. Both folders' topic hints are combined to preserve the information used for organization suggestions. Dropping a folder onto itself has no effect.

Drop targets highlight as you drag, and successful grouping or filing shows a brief connecting line. Conversation previews retain their drag surface: click to open, or drag to organize. The existing **All** breadcrumb lets you drag a conversation out of an open folder.

## Folder controls

Right-click a folder, or use the options menu inside an open folder, to:

- **Open** the folder or **rename** it.
- Choose **New constellation** to generate and save a different star pattern.
- Choose **Merge into…** and select a destination folder.
- **Dissolve folder · keep contents** to remove the folder and return its conversations and scratchpad pages to Unfiled.
- **Delete folder and contents…** to permanently remove the folder and everything inside it. A confirmation shows the conversation and page counts before deletion.

Manual merges preserve the selected scratchpad page and its content. Pending automatic folder names are canceled when a manual merge takes over. Removing or merging folders also clears an affected grouping-undo message so it cannot point at an obsolete group.

## Recording and appearance

![Murmur recording overlay with its voice-responsive indicator](https://raw.githubusercontent.com/krisekenes/murmur/v0.4.0/docs/releases/images/v0.4.0/recording.png)

- Midnight blue and charcoal surfaces, a sparse star field, and amber highlights throughout the Beta library.
- A glowing dot at rest that expands into bars responding to microphone input while recording. The recording overlay uses the same appearance.
- Short folder and grouping transitions that respect **macOS Reduce Motion**. The background stars are static, with no continuous animation.
- Direct empty-state instructions and clearer feedback when a search has no results.

Screenshots above are rendered from the app's SwiftUI views using synthetic conversations, not personal recordings.

## Compatibility and validation

- Existing notebooks load without requiring the new constellation field. Custom patterns persist across restarts without changing folder IDs or moving their contents.
- Deleting a folder's last scratchpad page leaves a valid blank notebook; unrelated folders, conversations, and pages remain intact.
- **89 core tests and 12 beta regression checks pass**, covering notebook compatibility, constellation persistence, merge preservation, deletion versus dissolution, and stale automatic naming responses.
- Release packaging builds the app, verifies its signature, and generates a SHA-256 checksum. Wide and compact UI previews were inspected.
- End-to-end drag gestures, fresh-Mac installation, microphone permissions, and model inference have not been revalidated as part of this release's automated checks.

History still retains the most recent **200 dictations**, including conversations filed in folders. This release does not change retention or add cloud storage.

## Download and update

Download **Murmur-0.4.0-macOS-arm64.zip** from the assets below. Quit Murmur, unzip the download, and replace Murmur in Applications. The `.sha256` file provides the archive checksum. Requires **Apple Silicon and macOS 14 or later**; models download separately on first use.

This is a **preview release, ad-hoc signed and not notarized**. See the [installation instructions](https://github.com/krisekenes/murmur/blob/v0.4.0/README.md#download-and-install) for macOS opening guidance. Accessibility permission may need to be granted again after replacing the app. If an enabled entry is not recognized, quit Murmur, remove the old Accessibility entry, add and enable the updated app, and reopen it.
