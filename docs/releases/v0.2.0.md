# Murmur 0.2.0 — macOS preview

Organize your conversations and scratchpad pages with tags and folders, and use Smart organize to review and apply suggested filing in a batch.

## What's new

- **Conversation tags:** existing and new conversations receive local, keyword-based topic tags. Tags appear on feed cards and can be added or removed in the conversation detail view.
- **Folders:** create, rename, and delete folders, and move conversations or scratchpad pages into them. Deleting a folder keeps its contents in Unfiled.
- **Smart organize:** preview folder suggestions for all unfiled conversations. Suggestions consider existing folder names, tags shared with previously filed conversations, and topic tags. Edit destinations or skip items before applying. Ambiguous matches remain unfiled.
- **Undo moves:** reverse the latest smart organization batch during the current app session. Conversations subsequently moved to another folder are preserved; created folders remain available.
- **Search and filters:** search conversation text or tags in the main search box and filter the feed by folder or tag.
- **Scratchpad organization:** add custom tags, accept local suggestions, and browse pages using inline search and folder/tag filters.

## Usability fixes

- Hovering or selecting a conversation now preserves its layout; Copy and Send controls fade into reserved space.
- Conversation organization lives directly in the feed and detail view. A dedicated Scratchpad button opens editable pages.
- Replaced the large floating page browser with an inline browser.
- Existing history and notebook files load with the new organization metadata. Removing an automatic conversation tag stays effective after restart.

## Download and update

Download **Murmur-0.2.0-macOS-arm64.zip** below, quit Murmur, and replace your app in Applications. The `.sha256` asset provides a checksum. GitHub's source archives are not installable apps.

Requires an Apple Silicon Mac and macOS 14 or later. Initial speech and polish model downloads require an internet connection. Tagging and folder suggestions run locally without additional model downloads or API keys.

## Preview limitations

- This app is ad-hoc signed and **not notarized**. See the README for installation guidance.
- macOS may require Accessibility permission to be granted again after replacing this preview build. If an existing enabled entry is not recognized, quit Murmur, remove the old entry from System Settings → Privacy & Security → Accessibility, add the updated app, enable it, and reopen Murmur.
- Smart organization uses keyword and tag matching; review suggestions before applying. It runs when requested and does not continuously file new conversations.
- History retains the most recent 200 dictations, including conversations assigned to folders. Folders do not change history retention.

## Validation

39 core tests pass, covering migration, tags, folder operations, suggestion matching, persistence, stale previews, and undo. The Release app builds and its ad-hoc signature is verified. Fresh-machine installation, microphone capture, and model inference have not been revalidated for this release.
